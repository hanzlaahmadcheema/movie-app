# Movie App Directory Explanation

This file explains the project structure from folders down to the important files. Generated folders such as `build/`, `.dart_tool/`, `.gradle/`, and IDE folders are listed separately because they are not source-code folders.

## Root Folder

```text
movie-app/
├── android/
├── assets/
├── docs/
├── ios/
├── lib/
├── linux/
├── macos/
├── test/
├── web/
├── windows/
├── .env
├── .env.example
├── analysis_options.yaml
├── firebase.json
├── firestore.rules
├── google-services.json
├── MASTER_AUDIT_REPORT.md
├── pubspec.yaml
├── pubspec.lock
└── README.md
```

### Root Files

- `.env`  
  Local environment values used by the Flutter app. This may contain private configuration and should not be treated as public documentation.

- `.env.example`  
  Example environment template showing which environment variables are expected.

- `analysis_options.yaml`  
  Dart and Flutter linting rules.

- `firebase.json`  
  Firebase project configuration for deployable Firebase resources.

- `firestore.rules`  
  Firestore security rules. This controls which users can read/write user data, admin collections, playback logs, and content requests.

- `google-services.json`  
  Android Firebase configuration file.

- `MASTER_AUDIT_REPORT.md`  
  Main project audit and phase-status report.

- `pubspec.yaml`  
  Flutter package configuration. Defines dependencies, assets, project metadata, and launcher icon configuration.

- `pubspec.lock`  
  Exact resolved dependency versions. This is generated by `flutter pub get`.

- `README.md`  
  Project overview/readme.

## `lib/` Main Flutter Source

```text
lib/
├── app/
├── core/
├── features/
├── widgets/
├── firebase_options.dart
└── main.dart
```

- `lib/main.dart`  
  Flutter entry point. Starts Firebase/app initialization and runs `MovieApp`.

- `lib/firebase_options.dart`  
  Firebase platform configuration generated by FlutterFire.

## `lib/app/`

```text
lib/app/
├── app_routes.dart
├── app_theme.dart
└── movie_app.dart
```

- `app_routes.dart` 
  Central route registry. Defines route names and maps them to screens. Also validates route arguments for detail, watch, streaming, Jellyfin, trailer, and admin routes.

- `app_theme.dart`  
  App-wide dark theme, colors, and text styles.

- `movie_app.dart`  
  Root `MaterialApp`. Owns the navigator key, navigation observer, splash startup route, and lifecycle behavior.

## `lib/core/`

`core/` contains reusable app logic that is not tied to one screen.

```text
lib/core/
├── auth/
├── config/
├── constants/
├── data/
├── jellyfin/
├── local_db/
├── models/
├── navigation/
├── services/
├── share/
├── streaming/
└── trailer/
```

### `lib/core/auth/`

- `current_user_role.dart`  
  Represents the current user role and status, including user/admin/super-admin checks.

- `user_role_service.dart`  
  Reads and watches the Firebase user document to determine role-based access.

### `lib/core/config/`

- `app_config.dart`  
  Loads app configuration such as TMDB settings and environment-based values.

### `lib/core/constants/`

- `app_assets.dart`  
  Central asset and logo URLs/paths used by UI.

- `app_legal.dart`  
  Text/configuration constants for Contact, Terms, and Privacy screens.

### `lib/core/data/`

- `mock_data.dart`  
  Static fallback/sample data. Real app screens primarily use TMDB/Firebase data.

### `lib/core/jellyfin/`

Private Jellyfin integration lives here.

- `jellyfin_client.dart`  
  Low-level Jellyfin HTTP/API client for login, server info, users/items, playback info, and progress APIs.

- `jellyfin_config.dart`  
  Local Jellyfin settings model, secure-token storage behavior, server URL validation, and playback mode.

- `jellyfin_index.dart`  
  Local match index for movies, series, and episodes.

- `jellyfin_item.dart`  
  Model for Jellyfin items returned by the Jellyfin API.

- `jellyfin_matcher.dart`  
  Matches TMDB/IMDb content to Jellyfin items.

- `jellyfin_playback_info.dart`  
  Models Jellyfin `PlaybackInfo`, media sources, streams, duration, and progress values.

- `jellyfin_repository.dart`  
  Higher-level Jellyfin repository used by playback and provider matching.

- `jellyfin_stream_url_builder.dart`  
  Builds native Jellyfin stream candidates safely.

- `jellyfin_url_builder.dart`  
  Builds Jellyfin Web URLs.

### `lib/core/local_db/`

Local sqflite cache. This is intentionally not used for secrets.

- `app_database.dart`  
  Opens the sqflite database and creates the `recent_searches` table.

- `recent_search_dao.dart`  
  Saves, lists, deduplicates, and clears recent search queries.

### `lib/core/models/`

TMDB and app data models.

- `detail_item.dart`  
  Detail page model for movie/series metadata.

- `movie_item.dart`  
  Main card/list model for movie and series content.

- `tmdb_option.dart`  
  Common option model for filters such as genre/country.

- `tmdb_page.dart`  
  Paginated TMDB response wrapper.

- `tmdb_person.dart`  
  Cast/person model.

- `tmdb_season.dart`  
  TV season and episode models.

- `tmdb_video.dart`  
  TMDB trailer/video model.

### `lib/core/navigation/`

- `app_navigation_observer.dart`  
  Observes route changes and persists safe restorable route state.

- `content_navigation.dart`  
  Helper functions for opening movie/series/detail/watch/search routes.

- `navigation_state_repository.dart`  
  SharedPreferences-backed navigation state for cold-start restore only.

- `watch_page_request.dart`  
  Typed route argument object for movie and series watch pages.

### `lib/core/services/`

- `admin_repository.dart`  
  Reads admin-managed Firestore configuration, dashboard stats, banners, notices, provider settings, and admin data.

- `auth_service.dart`  
  Firebase Auth wrapper for email login/register, Google auth, phone auth, profile update, password update, and sign out.

- `network_status_service.dart`  
  Lightweight network/offline checks.

- `tmdb_api_client.dart`  
  Low-level TMDB HTTP client.

- `tmdb_repository.dart`  
  Higher-level TMDB repository for home content, search, detail, cast, genres, countries, videos, and discovery filters.

- `user_activity_repository.dart`  
  Firestore user activity, Continue Watching, watched state, and watchlist-related writes/reads.

- `user_profile_repository.dart`  
  Firestore user profile synchronization.

### `lib/core/share/`

- `platform_share_service.dart`  
  Platform share/copy fallback abstraction.

- `share_actions.dart`  
  UI-facing share action handling.

- `share_text_builder.dart`  
  Builds safe user-facing share text without secrets or provider URLs.

### `lib/core/streaming/`

Public streaming provider and WebView support.

- `embed_url_builder.dart`  
  Builds VidSrc/2Embed embed URLs.

- `streaming_content_type.dart`  
  Movie/series/episode streaming type enum.

- `streaming_embed_request.dart`  
  Typed request for embedded player routes/panels.

- `streaming_embed_result.dart`  
  Streaming result/status models.

- `streaming_navigation_policy.dart`  
  WebView navigation safety policy, HTTPS-only public provider rules, and Jellyfin private-host exception.

- `streaming_provider_registry.dart`  
  Provider registry and ordering.

- `streaming_repository.dart`  
  Streaming candidate generation, provider fallback, retry state, and diagnostics.

- `streaming_server.dart`  
  Streaming provider/server model.

### `lib/core/trailer/`

- `trailer_picker.dart`  
  Chooses the best TMDB trailer or teaser and validates supported trailer sites.

## Data Storage Summary

- Firebase Auth stores user authentication state.
- Firestore stores user profiles, watchlist, watched state, Continue Watching, admin config, content requests, and safe playback logs.
- `flutter_secure_storage` stores sensitive local Jellyfin access token data.
- `SharedPreferences` stores non-secret settings such as navigation restore and Jellyfin local config.
- `sqflite` stores only local recent-search cache in `recent_searches`.
- TMDB data is fetched from the TMDB API and is not permanently stored as full app content.
